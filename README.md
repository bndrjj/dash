# 📊 دليل استخدام لوحة التحكم التفاعلية

## 🎯 نظرة عامة

لوحة تحكم احترافية مصممة بالكامل باللغة العربية مع دعم RTL، تعرض البيانات بشكل تفاعلي وجذاب. اللوحة تستخدم نظام ملفات JSON لتخزين البيانات، مما يجعل التعديل والتخصيص سهلاً جداً دون الحاجة لمعرفة برمجية متقدمة.

---

## 📦 محتويات المشروع

```
dash/
├── index.html          # ملف لوحة التحكم الرئيسي
├── data.json           # ملف البيانات القابل للتعديل
├── README.md           # دليل الاستخدام (هذا الملف)
└── .gitignore          # ملف لتجاهل الملفات غير المطلوبة في Git
```

---

## 🚀 البدء السريع

### 1️⃣ التثبيت والإعداد

```bash
# استنسخ المستودع
git clone https://github.com/bndrjj/dash.git

# انتقل إلى مجلد المشروع
cd dash

# افتح الملف مباشرة في المتصفح
# أو استخدم خادم محلي (موصى به)
python -m http.server 8000
# ثم افتح: http://localhost:8000
```

### 2️⃣ فتح لوحة التحكم

- **طريقة 1:** افتح ملف `index.html` مباشرة في المتصفح
- **طريقة 2 (موصى بها):** استخدم خادم محلي لتجنب مشاكل CORS عند تحميل `data.json`

## ✏️ تعديل البيانات

### 📄 هيكل ملف `data.json`

الملف مقسم إلى أقسام رئيسية:

#### 1. **رأس الصفحة (Header)**
```json
"header": {
  "title": "عنوان لوحة التحكم",
  "subtitle": "وصف مختصر",
  "date": "التاريخ"
}
```

#### 2. **الإحصائيات (Stats)**
```json
"stats": [
  {
    "icon": "📊",           // أيقونة (Emoji أو رمز)
    "value": "123",         // القيمة المعروضة
    "label": "التسمية",     // وصف الإحصائية
    "color": "default"      // اللون: default, accent-2, accent-3, accent-4
  }
]
```

#### 3. **الملفات (Files)**
```json
"files": [
  {
    "icon": "📄",
    "name": "اسم الملف",
    "description": "وصف الملف"
  }
]
```

#### 4. **الجدول الزمني (Timeline)**
```json
"timeline": [
  {
    "title": "عنوان الحدث",
    "description": "وصف تفصيلي للحدث"
  }
]
```

#### 5. **المميزات (Features)**
```json
"features": [
  {
    "text": "اسم الميزة",
    "color": "default"      // default, accent-2, accent-3
  }
]
```

#### 6. **الملخص (Summary)**
```json
"summary": {
  "title": "عنوان الملخص",
  "content": "محتوى الملخص التفصيلي"
}
```

## 🎨 تخصيص الألوان

يمكنك تعديل الألوان الأساسية من ملف `index.html` في قسم `:root`:

```css
:root {
    --primary: #0A1929;      /* اللون الأساسي الداكن */
    --secondary: #1E3A5F;    /* اللون الثانوي */
    --accent: #F7B731;       /* اللون المميز الرئيسي (ذهبي) */
    --accent-2: #FF6B6B;     /* لون مميز إضافي (أحمر) */
    --accent-3: #4ECDC4;     /* لون مميز إضافي (فيروزي) */
    --accent-4: #A8E6CF;     /* لون مميز إضافي (أخضر فاتح) */
}
```

## 📋 أمثلة عملية

### مثال 1: إضافة إحصائية جديدة

افتح `data.json` وأضف عنصراً جديداً في مصفوفة `stats`:

```json
{
  "icon": "🔥",
  "value": "500+",
  "label": "مستخدم نشط",
  "color": "accent-2"
}
```

### مثال 2: إضافة ملف جديد

أضف عنصراً في مصفوفة `files`:

```json
{
  "icon": "📝",
  "name": "تقرير شهري",
  "description": "تقرير تفصيلي عن الأداء الشهري"
}
```

### مثال 3: إضافة حدث في الجدول الزمني

أضف عنصراً في مصفوفة `timeline`:

```json
{
  "title": "إطلاق النسخة 2.0",
  "description": "تم إطلاق النسخة الجديدة بميزات متقدمة"
}
```
